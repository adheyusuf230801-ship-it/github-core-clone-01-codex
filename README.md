Forgehouse is a standalone GitHub-compatible git forge with smart HTTP, REST v3, GraphQL, and MCP. It runs in one process with an in-memory store and the Node 22 standard library only.

## Run it

```sh
node main.ts
```

MAKEFUN_ENV_URL must point at the trial env. Set MAKEFUN_SHOP_TOKEN to the trial bearer token. State is intentionally ephemeral; the server performs no filesystem writes.
